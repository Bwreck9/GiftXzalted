Prompt for Replit — Landing, Profiles, Questionnaire, Settings, Clipboard
You are updating the “Gift Spark” web app. 
Stack: React + React Router + Tailwind (or minimal CSS). Assume an auth provider for Google and a token balance in user state.

GOALS
1) Landing page shows “Sign in with Google” when logged out. 
   After sign-in, the landing shows the user’s profile cards (name + color), a Settings button, and a “New Profile Questionnaire” CTA.
2) Profiles have editable name and color. Provide Rename, Edit, Clear via Settings.
3) “New Profile Questionnaire” opens the questionnaire. User may fill without auth, but submission requires login + tokens. Preserve draft during sign-in.
4) Clicking a profile card opens that **single profile page** with manual fields (free) and a premium responses section (with “Copy to Clipboard” for each response).
5) “View profiles” opens a **profiles list page** showing all profiles at once in list format (header links to profile page), manual fields inline, premium responses below.
6) We don’t need chat history; just persist the table/list responses per profile (overwrite when re-run).
7) Add a global Settings control on the landing page that manages the selected profile: Rename, Edit color, Clear (confirm), Delete (optional).

HOOK — usePersistedDraft (TypeScript OK)
---------------------------------------
Create src/hooks/usePersistedDraft.ts:


import { useEffect, useRef, useState } from 'react';
export function usePersistedDraft<T = any>(key: string, initial: T) {
const [draft, setDraft] = useState<T>(() => {
try { return JSON.parse(localStorage.getItem(key) || 'null') ?? initial; }
catch { return initial; }
});
const t = useRef<number | null>(null);
useEffect(() => {
if (t.current) window.clearTimeout(t.current);
t.current = window.setTimeout(() => {
try { localStorage.setItem(key, JSON.stringify(draft)); } catch {}
}, 300);
return () => { if (t.current) window.clearTimeout(t.current); };
}, [key, draft]);
const clearDraft = () => { localStorage.removeItem(key); setDraft(initial); };
return { draft, setDraft, clearDraft, draftId: key };
}
